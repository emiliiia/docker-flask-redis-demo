Крок 9: Додаткові команди Docker Compose
•	Запуск у фоновому режимі: docker compose up -d
•	Перевірка робочих контейнерів: docker compose ps
•	Зупинка сервісів: docker compose stop
•	Повне видалення: docker compose down
 

Висновки
1)	Docker Compose значно спрощує роботу з багатоконтейнерними додатками.
2)	Використання YAML-файлу дозволяє описувати всі сервіси, мережі та томи в одному місці.
3)	Інструменти Docker (Desktop/CLI) є стандартом для сучасного розгортання додатків.
4)	Compose Watch значно пришвидшує розробку (немає потреби перезапускати контейнери вручну).
5)	Розділення сервісів через include покращує структуру проектів.
6)	Docker Compose надає гнучкі інструменти для керування багатоконтейнерними додатками.
